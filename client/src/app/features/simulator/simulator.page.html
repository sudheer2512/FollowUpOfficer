How it works

FollowUp Officer talks to this emulated tenant through the real Microsoft Graph client — the same code, endpoints, paging and delta queries it uses against Microsoft 365.

  1. Act as anyone. Send and reply to email, chat and post in channels as any user of the tenant.
  2. The normal sync imports it. Outlook and Teams sync jobs pick messages up on their next run (or use “Run sync now” in the integration monitor), and replies are matched to their tasks.
  3. Break things on purpose. Inject outages, throttling, auth failures and latency to watch retries, backoff, checkpoints and resyncs.
